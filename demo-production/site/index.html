01WHAT WENT WRONG

A green result
needs a real contract.

Trivy’s native JSON has an envelope that identifies the report: schema, artifact, type, and scanner version. If those fields are missing or malformed, an empty findings list is not proof of a clean scan.

The vulnerable parser could accept report shapes without validating that complete native envelope. PR #11 tightened the contract while preserving the project’s normalized scanner formats.
