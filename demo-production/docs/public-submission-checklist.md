# Public submission checklist

- [x] Report uses public PR/commit facts only.
- [x] No credentials, environment values, raw scanner logs, or private Discord
  message URLs are embedded.
- [x] Historical fixes are labeled with their original date/revisions.
- [x] Check the final video's opening, representative middle frames, PR diff,
  and ending; keep the earlier PR conversation capture out of the shareable set.
- [ ] Check every final video frame for unrelated Discord servers, DMs, names,
  tokens, runtime configuration, or private logs.
- [ ] Confirm every live claim has a corresponding raw capture and receipt.
- [x] Confirm all visible SHAs/URLs against source evidence.
- [x] Site URL opened successfully; video has no narration or captions to mismatch.
- [x] The demo did not change repository visibility; the owner made the repository public.
- [ ] Ask the second participant before recording their face, voice, or private
  account content; screen recording should show only the demo session.
